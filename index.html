Features

Everything in 1.3.0.

Terminals

  • Save SSH servers, each opens as its own tab.
  • Local shells: Command Prompt, Windows PowerShell or PowerShell 7, with an optional start folder.
  • Start folders accept %USERPROFILE% and ~.
  • “This PC” opens a default local shell.

SFTP file browser

  • The “Files” button opens a panel beside the terminal.
  • Browse, jump to a path, go up, reload.
  • Download files and whole folders.
  • Upload by button or drag and drop.
  • Rename, delete and create folders.

AI assistant

  • Check this tab explains what is wrong and how to fix it.
  • Explain last output puts errors in plain words.
  • Answers in the language you write in.
  • Commands appear in boxes: Copy or Insert in terminal. The AI never runs anything by itself.
  • Untick Share the current tab with the AI for sensitive data.

Cloud sync

  • Servers, local shells and folders are stored in an end-to-end encrypted vault.
  • The newest change wins; deletions sync across your PCs.
  • Optional: NNTerminal works fully without an account.

Share servers

  • Open Edit → Share access and enter an email.
  • The other person accepts or declines. Nothing connects before that.
  • End access any time with Remove access.
  • Changes reach the other person automatically, key files included.
  • A key fingerprint is shown so you can compare it.

Password lock

  • Enable in Settings → Security, then set a password per server.
  • Locked servers keep terminal and file browser closed.
  • Lock locks a server again immediately.
  • Applies only to this PC and is not synced.

Folders

  • Group servers and shells in sidebar folders.
  • Drag and drop, collapse, rename, reorder.
  • Deleting a folder keeps its servers.
  • The overview groups servers by folder.

More

  • Overview with status and load of all servers.
  • Linux Help, Uptime Kuma and Use Linux Distros tabs.
  • Automatic updates checked on start, hourly and when you return to the window.
  • Themes with presets and custom fonts.

Changelog

Every release so far, newest first.

1.3.0Current

Local shells, folders and an AI assistant

  • Saved local shells (Command Prompt, PowerShell, PowerShell 7) with start folders and %VARIABLES% support.
  • Sidebar folders for servers and shells.
  • AI assistant panel with “Check this tab” and “Explain last output”, powered by Groq.
  • Local shells and folders are included in cloud sync.

Older versions do not know local shells and would remove them during cloud sync. Update all your PCs before logging in with 1.3.0. To share or receive servers, everyone needs 1.3.0 and has to sync once.

1.2.0

Sharing, SFTP and automatic updates

  • Share servers with other NNTerminal users, end-to-end encrypted.
  • SFTP file browser next to the terminal.
  • Password lock per server.
  • Use Linux Distros tab (distrosea.com), styled to match.
  • Automatic updates for the installer, a download hint for the portable version.
1.1.0

New layout and optional cloud account

  • Tabs moved to a sidebar on the left; new overview with summary cards and one card per server.
  • Cloud account with AES-256-GCM encryption on your PC before upload. Newer change wins, deletions propagate.
  • Logout removes all servers from the PC; they return from the cloud on next login.
  • Uptime Kuma tab showing per-monitor status from a public status page.
  • Embedded 20-minute Linux machine.
1.0.0First release

SSH terminal with live dashboard

  • Saved SSH servers, each with its own tab and full terminal.
  • Live dashboard for CPU, RAM and storage, refreshed every 3 seconds.
  • Auto-connect and auto-reconnect every 15 seconds.
  • Password or key file login.
  • This PC local shell tab and Linux Help tab (cheat.sh).
  • Draggable tabs, themes (Default, Dracula, Nord, Gruvbox) and font settings.
  • Windows installer and portable build.

Requirements

System

  • Windows PC.
  • cmd and Windows PowerShell are Windows-only.
  • PowerShell 7 must be installed separately.

Network and privacy

  • Internet is needed for cloud sync, sharing, the AI assistant and updates.
  • The AI assistant sends your question, and the visible tab content if enabled, to Groq.
  • Server monitoring reads values over SSH and works on Linux servers.
