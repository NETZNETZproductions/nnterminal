## Why NNTerminal?

- **All your servers in one window** – one tab per server, connected automatically and reconnected if the line drops.
- **See everything at a glance** – the Overview shows CPU, RAM and storage of every server, live.
- **Real local shell** – the *This PC* tab is a full terminal (`cmd.exe` on Windows), not a simulation.
- **Linux Help built in** – look up `tar`, `find`, `chmod` and more as clean example cards with a copy button.
- **Yours to customize** – drag tabs into any order, pick a theme preset or set your own colors and fonts.
- **Private by design** – no account, no telemetry, no auto-update. Passwords are encrypted with your system's secure storage.

## Install

1. Open the [Releases](../../releases) page.
2. Download **`NNTerminal Setup 1.0.0.exe`** (installer) or the **portable** exe.
3. Start it. If Windows SmartScreen warns you, click *More info → Run anyway* (the app is not code-signed yet).

## Quick start

1. Click **+** in the tab bar.
2. Enter name, address, user and password (or a key file).
3. Save – the server connects on its own. Click the tab to open its terminal.
